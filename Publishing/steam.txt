[h1]Better ReGrowth 2 Boulder Names[/h1]

[h2]Features[/h2]

This mod patches the [url=https://steamcommunity.com/sharedfiles/filedetails/?id=2260097569]ReGrowth 2[/url] mod to rename boulders which contain ore.

[list]
    [*]Boulders that contain ore will be named like [b]"Sandstone boulder (plasteel)"[/b] instead of just [b]"Sandstone boulder"[/b]
    [*]This enables the RimWorld search function to find ([b]hotkey "Z"[/b]) boulders containing ores easily.
[/list]

Why? Because when traveling around the rimworld, checking boulders for interesting ores can be ... tiresome.

And some resources are quite rare, so FOMO.

This mod lets the player find them all at a glance.
